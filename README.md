# One Piece Battle Arena

Juego de peleas por turnos inspirado en One Piece, ahora con modo campaña y desbloqueo progresivo de Gear.

## Campaña

Supera los niveles en orden:

1. Rob Lucci
2. Donquixote Doflamingo
3. Charlotte Katakuri
4. Kaido

## Sistema de Gear

Cada jefe derrotado desbloquea la siguiente transformación de Luffy:

- Gear 1 (inicio)
- Gear 2
- Gear 3
- Gear 4
- Gear 5

## Cómo jugar

1. Abre `index.html` en tu navegador.
2. Usa **Puño básico** o **Técnica Gear**.
3. Al vencer un jefe pasas al siguiente nivel automáticamente.
4. Si pierdes, pulsa **Reiniciar campaña**.
