# One Piece Battle Arena

Juego de peleas por turnos inspirado en One Piece.

## Cómo jugar

1. Abre `index.html` en tu navegador.
2. Elige tu personaje.
3. Usa **Ataque básico** o **Ataque especial**.
4. Gana bajando la vida del enemigo a 0.

## Personajes

- Monkey D. Luffy
- Roronoa Zoro
- Vinsmoke Sanji
- Portgas D. Ace
